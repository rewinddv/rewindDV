# Project identity

The software license does not grant rights to the rewindDV name, logo or Azimuth
Mark. Project branding remains separate from Apache-2.0 and from third-party
software licenses. No upstream endorsement or trademark registration is implied.

The documentation retains the previously published cassette artwork and sponsor
heading from the former LAB repository under `assets/`. These project-presentation
assets are separate from the software license and grant no trademark rights.
Source builds continue to use the system's generic application icon; no app
resource or build input changed during consolidation. The reference photograph
is not included. New branding assets require an explicit asset notice and owner
approval.

## Support development

[Support rewindDV on Ko-fi](https://ko-fi.com/rewinddv). Funds raised go toward purchasing
IEC standards to research all the metadata these tapes can contain and expand
what rewindDV can decode. These primary references help us interpret recorded
packs and fields against documented requirements.

Support is optional and does not buy compatibility, recovery guarantees or a
release date. Purchased standards are not redistributed. Funding does not change
the software license or imply endorsement by IEC or upstream projects.
